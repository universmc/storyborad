En respectant les normes du Web sémantique W3C, il est possible d'ajouter des attributs `aria-label` ou `title` sur les différents éléments de l'interface pour améliorer l'accessibilité de celle-ci.

Exemple:
```php
<button aria-label="bouton pour sauvegarder les modifications">Save</button>
```
ou
```python
<input type="text" title="champ pour rentrer une adresse email">
```
Pour permettre une bonne navigation par tabulation et une bonne lecture par les lecteurs d'écran.
